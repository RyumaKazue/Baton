# Baton MVP（案）

最終更新：2026-09-29

仕様の全体は [spec.md](spec.md) を参照。

## 1. MVPのゴール

**Mac 2台で、次の2つを毎日使える状態にする。**

1. 登録機器が、どのMacに接続中かを確認できる
2. 接続先のMacを操作するだけで、機器をもう一方のMacから切り替えられる

仕様の中で最も不確かな「IOBluetoothで音声までつながるか」を早い段階で確かめ、アプリとして成り立つかを判断することも目的にする。

## 2. 進め方

| 段階 | 内容 | 完了の条件 |
|---|---|---|
| ステップ0：検証 | 仮のコードでIOBluetoothの接続・切断を試す | 実機のイヤホンで、接続すると音声が流れ、切断すると止まる |
| **MVP（v0.1）** | Mac → Mac の切り替え | 下の「3. MVPに含める機能」がすべて動く |
| v0.2 | 使い勝手と安全性 | 設定・通知・スリープ・ペアリングなど（→ 4） |
| v0.3 | iPhoneアプリ | Mac → iPhone の切り替え |
| 将来 | 鍵交換（ECDH）によるペアリング | 仕様書 9 |

## 3. MVPに含める機能（Macアプリのみ）

| 機能 | MVPでの範囲 | 仕様書 |
|---|---|---|
| メニューバー常駐 | メニューバーにアイコンを出す。Dockには出さない | 5.1 |
| Bluetooth機器の登録と解除 | ペアリング済みの機器から選んで登録・解除する | 5.1 |
| このMacでの接続と切断 | 登録機器を、このMacで接続・切断する | 5.1 |
| 他のMacの発見 | Bonjourで同じLAN内のMacを見つける | 8 |
| 接続状態の表示 | 登録機器ごとに、どこに接続中か（だったか）をまとめて表示する。応答のないMacは、最後に確認できた時刻・状態を表示する | 5.1、6.3、6.5 |
| このMacへの切り替え | 接続元に切断を依頼し、このMacで接続する。応答のないMacがあってもそのまま接続を試す | 6.1、6.3 |
| 切断依頼の受け付け | 他のMacからの切断依頼を受けて切断し、結果を返す | 5.1 |
| エラーの表示 | 応答なし、切断の失敗、接続の失敗、ネットワークなし | 10 |
| ログイン時の自動起動 | オン・オフの切り替えはメニューから行う | 5.1 |
| スリープ時の切断と復帰時の再接続 | 登録機器すべてに適用する（機器ごとのオン・オフはv0.2） | 7 |
| スリープ前の知らせ | スリープに入るときに sleep を送り、受け取った側は記録を更新して「スリープ中」と表示する | 6.5 |

### MVPでの簡略化

| 項目 | MVPでの扱い | 本来の仕様 |
|---|---|---|
| 表示名 | コンピュータ名をそのまま使う（変更できない） | 設定で変更できる |
| 応答の待ち時間 | 5秒で固定 | 設定で1〜30秒 |
| スリープ時の処理 | 登録機器すべてで有効 | 機器ごとにオン・オフできる |
| 端末の認証・暗号化 | なし（同じLAN内の端末を信用する）。自宅のWi-Fiだけで使う | ペアリング済みの端末だけ受け付け、TLS-PSKで暗号化 |

## 4. MVPに含めない機能（v0.2以降）

| 機能 | 時期 |
|---|---|
| 設定画面（表示名の変更、応答の待ち時間、通知のオン・オフ、機器ごとのスリープ設定） | v0.2 |
| 切断時の通知 | v0.2 |
| 端末のペアリング（PIN）とTLS-PSKによる暗号化、ペアリング済み端末の一覧・解除 | v0.2 |
| iPhoneアプリ全体 | v0.3 |
| 鍵交換（ECDH）によるペアリング | 将来 |
| 登録機器の同期 | 未定（仕様書 14.2） |
| 接続状態のリアルタイム同期 | 未定（仕様書 14.2） |

## 5. MVPの範囲で決めたこと

| # | 項目 | 決定 |
|---|---|---|
| 1 | 端末のペアリングと暗号化 | v0.2に回す。MVPの間は同じLAN内の端末を信用し、自宅のWi-Fiだけで使う |
| 2 | ログイン時の自動起動 | MVPに入れる |
| 3 | スリープ時の処理 | MVPに入れる。スリープ中のMacは切断依頼に応答できず、接続を取り戻せないため |
| 4 | status の問い合わせ方 | Bluetoothアドレスを指定して問い合わせる（仕様書 8） |
| 5 | 対応OSの下限 | macOS 14 以上・iOS 17 以上。App SandboxはONのまま |

## 6. MVPで検証すること

| 項目 | 確かめ方 |
|---|---|
| IOBluetoothで音声までつながるか | ステップ0で、実機のイヤホンで確かめる |
| IOBluetoothをSandboxの中で使えるか | ステップ0で、Bluetoothのentitlementを付けて確かめる |
| Macのスリープ中のイヤホンの接続 | ステップ0で、スリープの前後に接続状態を見る。スリープ時の切断が確実に動くかも確かめる |
| ローカルネットワークの許可 | 他のMacの発見を作るときに、初回に出る許可ダイアログを確かめる |
| 2台のMacでの切り替え | MVPの完成時に、2台目のMacで実際に切り替える |
