# Baton MVP

最終更新：2026-10-07

仕様の全体は [spec.md](spec.md)、開発の進め方は [plan.md](plan.md) を参照。

## 1. MVPのゴール

**この Mac 1台で、次のことを毎日使える状態にする。他の端末とのやり取りはしない。**

1. 登録したイヤホンを、メニューから接続・切断できる
2. Mac がスリープに入るときにイヤホンを手放し、他の端末（iPhone など）ですぐに使えるようにする
3. スリープから復帰したら、スリープ前に使っていたイヤホンを取り戻す

### この範囲にした理由（2026-10-07 の見直し）

- スリープ時の切断と復帰時の再接続の方が、他の端末との切り替えより、毎日の恩恵が大きい
- この Mac だけで完結するので、2台目の Mac や通信の仕組みがなくても作れて、早く使い始められる
- 他の端末とのやり取り（通信、他の端末の接続状態の表示、他の端末に切断を頼む切り替え）は、v0.2 で行う

## 3. MVPに含める機能（Mac アプリのみ）

| 機能 | MVPでの範囲 | 仕様書 | 状態 |
|---|---|---|---|
| メニューバー常駐 | メニューバーにアイコンを出す。Dock には出さない | 5.1 | ✅ |
| ログイン時の自動起動 | オン・オフの切り替えはメニューから行う | 5.1 | ✅ |
| Bluetooth 機器の登録と解除 | ペアリング済みの音声機器から選んで登録・解除する | 5.1 | ✅ |
| この Mac での接続と切断 | 登録機器を、メニューからこの Mac で接続・切断する。失敗したらメッセージを出す | 5.1、10 | ✅ |
| この Mac での接続状態の表示 | 登録機器ごとに、この Mac に接続中かを表示する | 5.1 | ✅ |
| スリープ時の切断 | スリープに入るときに、接続中の登録機器を切断し、記録する | 7 | フェーズ4 |
| 復帰時の再接続 | スリープ前に接続していた機器に、接続を試す。失敗したらあきらめる | 7 | フェーズ4 |

### MVPでの簡略化

| 項目 | MVPでの扱い | 本来の仕様 |
|---|---|---|
| 「切り替え」 | この Mac で「接続」を押すだけ。他の端末で使用中なら、接続が失敗してメッセージが出る | 他の端末に切断を頼んでから接続する（仕様書 6.1） |
| 復帰時の再接続の判断 | 他の端末に問い合わせず、接続を試す。他の端末で使用中なら接続が失敗するので、あきらめる | 他の端末に問い合わせ、使っていなければ接続する（仕様書 7） |
| スリープ時の処理 | 登録機器すべてで有効 | 機器ごとにオン・オフできる |

| 切り替え（他の端末に切断を頼んでから接続する）と、切断依頼の受け付け | v0.2 |
| スリープ前の知らせ（sleep メッセージ）と、復帰時の他の端末への問い合わせ | v0.2 |
| 端末のペアリング（PIN）と TLS-PSK による暗号化 | v0.2 |
| 端末の表示名、応答の待ち時間 | v0.2 |
| 切断時の通知（他の端末からの依頼で切断したとき） | v0.2 |

## 5. MVPの範囲で決めたこと

| # | 項目 | 決定 |
|---|---|---|
| 1 | MVP の範囲 | この Mac だけで完結する機能にする（2026-10-07） |
| 2 | ログイン時の自動起動 | MVP に入れる |
| 3 | スリープ時の処理 | MVP に入れる。スリープ中もヘッドホンがつながったままになるため（[検証結果](spikes/iobluetooth.md) 4.4） |
| 4 | 復帰時の再接続 | 他の端末に問い合わせず、接続を試す。失敗したらあきらめる |
| 5 | 対応 OS の下限 | macOS 14 以上。App Sandbox は ON のまま |

## 6. MVPで検証すること

| 項目 | 確かめ方 | 時期 |
|---|---|---|
| Mac から切断した後に、ヘッドホンの電源を入れ直すと、どこにつながるか | 実機で試す | フェーズ4の最初 |
| スリープ中の Mac に、ヘッドホンの側からつなぎに来るか | 実機で試す | フェーズ4の最初 |
| 他の端末とつながっているヘッドホンに、Mac から接続するとどうなるか（失敗する／奪う／2台同時） | EDIFIER と iPhone で試す | フェーズ4の最初 |
| 長時間のスリープでも、スリープ時の切断と復帰時の再接続が動くか | 一晩スリープさせて試す | フェーズ4の最後 |
