## メモ

- D1・D4 を行った時間帯（2026-10-07 20時以降）の電源ログに、Sleep の記録がなかった。スリープの通知の後に、スリープが取りやめになっていた可能性がある（その場合も、「離れた」で切断・「戻ってきた」で再接続されるので、見た目は期待どおりになる）
- D6（一晩のスリープ）は、受け入れテストの必須から外し、v0.1 を1週間使う中で確かめる（2026-10-08 に決定）。自動でスリープするのを待っても、ヘッドホンの接続や音楽の再生がスリープを止めるため、意図して試すのが難しい。1週間の間に、本当にスリープした後（電源ログに `Sleep` の記録があるとき）の再接続を、Baton のログで確かめる
- 本当にスリープした状態での切断は、受け入れテストの前（2026-10-07 14:58、電源ログに Software Sleep の記録あり）に確認済み
- F は、Baton のログで裏付けを取った。F3：14:01:34 と 14:01:45 に「離れる（ロック）：設定がオフなので切断しない」（E2）。F4：14:01:54 に「離れる（スリープ）：〜を切断して記録する」、14:01:58 に再接続。F5：14:02:55 に「離れる（画面の消灯）：〜を切断して記録する」、14:03:26 に再接続
- F4 も、電源ログに Sleep の記録がなく、画面が3秒で点き直していた（D1・D4 と同じく、スリープが取りやめになった可能性がある）。切断と再接続は期待どおり
