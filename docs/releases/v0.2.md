# Baton v0.2

この Mac での使い勝手を磨いたリリースです。v0.1 の機能に加えて、次のことができるようになりました。

## 新しくできること

- **離れている間は手放し続ける**：Mac をスリープ・ロックして離れている間に、ヘッドホンが Mac につなぎに来ても、Baton がすぐに切断します。iPhone など他の端末で、そのまま使えます。戻ってきたら、つなぎ直します
- **接続したら、音をヘッドホンから出す**：Baton で接続したときに、音の出力先をそのヘッドホンに切り替えます。外部モニターにつないでいても、音がモニターから出たままになりません
- **再生中は接続を維持**：音楽や動画を聴きながら画面をロックしても、切断せずに聴き続けられます。音声が止まって30秒経ってから切断します（設定でオフにできます）
- **設定の画面**：メニューの右上の歯車から開きます。切断するタイミング（画面のロック・スリープ・画面の消灯）、再生中は接続を維持、ログイン時に起動、を選べます
- **アイコン**：メニューバーのアイコンで、接続状態が分かります（斜線入り＝未接続、ふつう＝接続中、点の付いた絵＝接続・切断の途中）。アプリのアイコンも付きました

## 直した不具合

- 電池が切れかけて深いスリープに入り、充電して起きた後に、Baton が Bluetooth の接続・切断を正しく扱えなくなる不具合を直しました。macOS の Bluetooth の仕組みが起動し直したことに気づいて、Baton が自分で起動し直します
- 同じ機器を続けて切断したときに、2回目が「時間切れ」の失敗になることがある不具合を直しました
- 接続に失敗したときのメッセージは、メニューを閉じたら消えるようにしました

## 動作環境

- macOS 14 以上

## インストール

リポジトリの直下で、次のスクリプトを実行します（Xcode 26.3 が必要です）。

```bash
./scripts/install-release.sh
```

## 既知の制約

- 電池切れの深いスリープから起きた後は、Baton が起動し直すため、ロックを解除してもヘッドホンは自動で再接続されません。メニューから接続してください
- Baton を起動してから30秒以内に macOS の Bluetooth の仕組みが起動し直したときは、Baton は起動し直しません（繰り返しを防ぐため）。ヘッドホンの接続状態がおかしいときは、Baton を終了して起動し直してください
- 戻ってきたときの再接続は、他の端末に問い合わせずに試します。他の端末で使用中なら接続に失敗し、何も表示せずにあきらめます
- 離れている間に同じヘッドホンが5分間に3回を超えてつなぎに来たら、電池を守るために、それ以上は切断しません
