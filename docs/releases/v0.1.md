# Baton v0.1

Baton の最初のリリースです。この Mac だけで完結する機能を使えます。

## できること

- **メニューバーに常駐**：Dock には出ません。ログイン時に自動で起動できます
- **機器の登録**：ペアリング済みの音声機器から、Baton で管理する機器を選んで登録します
- **接続と切断**：登録した機器を、メニューから接続・切断できます。この Mac に接続中かを表示し、失敗したときは理由を案内します
- **離れるときに手放す**：スリープに入るとき・画面をロックしたとき（電源ボタン、ふたを閉じる など）に、接続中の機器を切断します。他の端末から、すぐにその機器を使えます
- **戻ってきたら取り戻す**：ロックを解除したときに、離れる前に使っていた機器を再接続します

## 動作環境

- macOS 14 以上

## インストール

リポジトリの直下で、次のスクリプトを実行します（Xcode 26.3 が必要です）。

```bash
./scripts/install-release.sh
```

## 既知の制約

- スリープ中にヘッドホンの電源を入れ直すと、ヘッドホンが最後に接続した端末（この Mac）につなぎに来て、スリープ中の Mac に接続されます（`docs/spikes/sleep-reconnect.md`）
- 戻ってきたときの再接続は、他の端末に問い合わせずに試します。他の端末で使用中なら接続に失敗し、何も表示せずにあきらめます
- 出力先がモニター（DELL S2725HS など）のときは、接続しても音声の出力先が自動でヘッドホンに切り替わらないことがあります（`docs/spikes/iobluetooth.md` 4.2）
